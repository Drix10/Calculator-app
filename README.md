# Calculator App for Android (MIT App Inventor)

A simple **calculator app for Android** that adds, subtracts, multiplies and divides. Built with [MIT App Inventor](https://appinventor.mit.edu/), a block-based tool for making Android apps.

## Files

- `Screen1 (1).scm`: the screen layout
- `project (1).properties`: project settings
- `images (1).png`, `images(1).jpeg`: app images

## Open it

Import the project into [MIT App Inventor](https://ai2.appinventor.mit.edu/), then build the APK or test it live with the MIT AI2 Companion app.
